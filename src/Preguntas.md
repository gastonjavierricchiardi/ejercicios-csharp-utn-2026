# Preguntas para hacernos:

1. ¿QUÉ ES? → posibles clases

2. ¿QUÉ TIENE? → atributos

3. ¿QUÉ SABE HACER? → métodos

4. ¿QUÉ DEBE TENER AL NACER? → constructor

5. ¿QUÉ PUEDE LEERSE / MODIFICARSE? → encapsulamiento

6. ¿QUÉ ES COMÚN? → posible clase base

7. ¿QUÉ ES PARTICULAR? → posibles subclases

8. ¿UNA CLASE ES UNA OTRA? → validar herencia con “ES UN”
