23:     */

26:     Si lo que queremos ahora es una property
27:     Metodo()        // paréntesis
28:     Property { }    // llaves

31:

33:     {

55:         name = value.Trim();
56:     }

59: /*
60: 1. El **Stack overflow** viene de `LastName`: la property se llama a sí misma sin parar.
61: 
62: ```csharp
63: public string LastName
64: {
65:     get { return LastName.Trim().ToUpper(); }
66:     set { LastName = value; }
67: }
68: ```
69: 
70: Cuando hacés:
71: 
72: ```csharp
73: unaPersona.LastName = "ricchi";
74: ```
75: 
76: entra al `set`:
77: 
78: ```text
79: set → LastName = value
80:           ↓
81:        llama al set
82:           ↓
83:        llama al set
84:           ↓
85:        llama al set...
86: ```
87: 
88: Por eso te dice:
89: 
90: ```text
91: Repeated 261662 times:
92: at Persona.set_LastName(System.String)
93: ```
94: 
95: 2. Necesitás un **atributo privado de respaldo** para guardar realmente el apellido, igual que ya hacés con `name`:
96: 
97: ```csharp
98: public class Persona
99: {
100:     private string name;
101:     private string lastName;
102: 
103:     public string LastName
104:     {
105:         get { return lastName.Trim().ToUpper(); }
106:         set { lastName = value.Trim(); }
107:     }
108: 
109:     public string GetName()
110:     {
111:         return name.Trim().ToUpper();
112:     }
113: 
114:     public void SetName(string value)
115:     {
116:         name = value.Trim();
117:     }
118: }
119: ```
120: 
121: Ahora queda clarísimo:
122: 
123: ```text
124: LastName   → property pública
125: lastName   → atributo privado donde guardamos el dato
126: ```
127: 
128: 3. Y el warning de `name` y ahora también `lastName` es **otro tema distinto**: C# te avisa que los `string` podrían arrancar sin valor. No es lo que produjo el `Stack overflow`.
129: 
130: Primero quedémonos con esta idea, que es la importante: **una property personalizada no debe hacer `LastName = ...` dentro de su propio `set`; necesita guardar el valor en otro campo, por ejemplo `lastName`.**

9:     private Herramienta herramienta;
10: 
11:     // 2. CONSTRUCTOR
12:     public Dron(Herramienta herramienta)
13:     {
14:         this.velocidadBase = 5;
15:         this.alturaBase = 100;
16:         this.pesoSinPenalizacion = 200;
17:         this.herramienta = herramienta;
18:     }
19: 
20:     // 3. PROPIEDADES / GETTERS Y SETTERS

22:     {

24:         set => herramienta = value;

26:     // 4. MÉTODOS
27:     // Calculamos los bloques extras que según el enunciado son cada 50
28:     public double CantidadBloquesExtra()
29:     {
30:         double pesoExtra = this.herramienta.Peso - this.pesoSinPenalizacion;
31: 
32:         if (pesoExtra <= 0) // Si peso extra, es menor o igual a 0 regresamos 0 (No hay peso extra según el enunciado)
33:         {
34:             return 0;
35:         }
36:         // Cada 50 gramos extra representan un bloque de penalización.
37:         // Las herramientas de la consigna producen excesos múltiplos de 50.
38:         return pesoExtra / 50;
39:     }
40:     // Calculamos la velocidad final
41:     public double CalcularVelocidadFinal()
42:     {
43:         double porcentajePenalizacion = this.CantidadBloquesExtra() * 0.02; // La cantidad de bloques *0.02
44:                                                                             // Pedimos la velocidad base y le restamos (la velocidad base  * porcentaje de penalización)
45:         return this.velocidadBase - (this.velocidadBase * porcentajePenalizacion);
46:     }
47:     // Lo mismo con la altura, hacemos los calculos
48:     public double CalcularAlturaFinal()
49:     {
50:         double porcentajePenalizacion = this.CantidadBloquesExtra() * 0.05;
51: 
52:         return this.alturaBase - (this.alturaBase * porcentajePenalizacion);
53:     }
54: 
55:     // Mostramos los datos
56:     public string GetInfo()
57:     {
58:         return $"Velocidad: {this.CalcularVelocidadFinal()} m/s, " +
